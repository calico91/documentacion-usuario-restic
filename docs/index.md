# Manual de Usuario — Restic

Bienvenido al manual de usuario de **Restic**, la aplicación móvil que te ayuda a
operar tu restaurante o heladería: tomar pedidos, cobrar, gestionar el menú,
controlar caja e inventario, y mucho más, todo desde tu teléfono o tablet Android.

## ¿Para quién es este manual?

Este manual está dirigido a:

- **Meseros y mozos** — toma de pedidos, gestión de mesas.
- **Cajeros** — apertura y cierre de caja, cobros, egresos.
- **Cocineros** — comandas (vista de cocina).
- **Administradores de sucursal** — gestión de menú, usuarios, inventario,
  configuración de impresoras, reportes, datos fiscales.
- **Propietarios y supervisores** — reportes de ventas, conciliación de cierres.

## ¿Qué cubre?

- Instalación, inicio de sesión y selección de sucursal.
- Ciclo POS del día a día: tomar pedido → comandas → cobro → cierre de caja.
- Administración de menú, mesas, clientes, usuarios, métodos de pago, inventario,
  datos fiscales.
- Configuración de impresoras térmicas (Bluetooth y red).
- Reportes de ventas y exportación de datos.
- Solución de problemas comunes.

## ¿Qué NO cubre?

- Administración global de la suscripción SaaS (planes, facturación mensual del
  servicio): se gestiona desde el portal web.
- Configuración del servidor backend: tarea del equipo de TI.

## Cómo usar este manual

- **Si buscas algo concreto**: usa el buscador (arriba) o el índice lateral.
- **Si eres nuevo**: lee primero [Requisitos](requisitos.md), luego
  [Instalación y actualización](instalacion-actualizacion.md) y
  [Iniciar sesión](iniciar-sesion.md).
- **Si necesitas un paso a paso**: cada sección tiene una lista numerada con el
  flujo completo, capturas y advertencias.
